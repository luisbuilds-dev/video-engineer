# Agents

This kit is built for Claude Code (skills in `.claude/skills/`, instructions in `CLAUDE.md`).
Other agents (Codex, Cursor, Gemini CLI…) can use it too: read `CLAUDE.md` for the rules and follow the steps of each `SKILL.md` by hand. The scripts (`npm run transcribir | cortar | render | revisar`) work the same from any terminal.
